# 体育館使用予約サイト

## ファイル
- index.html：予約画面
- admin.html：管理画面
- style.css：デザイン
- app.js：予約処理
- admin.js：管理画面処理

## 使い方
index.htmlをブラウザで開き、使用日・部活動・時間・A/B面を選択して予約します。
予約データはブラウザのlocalStorageに保存され、admin.htmlで確認できます。

## 注意
このバージョンはHTML/CSS/JavaScriptのみで作成しているため、データ保存先は「そのブラウザ」です。
別のスマホ・PCから同じ予約情報を見るには、後からサーバーやGoogle Apps Script等の共有データベースを追加する必要があります。

## 仕様
- A面、B面、A+B両方の予約
- 30分単位
- 同じ面で時間が重なる予約を自動拒否
- 使用する部活動を選択
- 管理画面トップに予約一覧を表示
- 管理画面で「開始日〜終了日」「開始時刻〜終了時刻」「部活動」「面」で絞り込み
- 予約削除
- ログインパスワードなし
